# how-bidirectional-rnn-works

양방향(Bidirectional) RNN은 어떻게 동작하는가 — **미래를 보는 대가**. `bidirectional=True` 한 글자가 정확도를 올리는 대신 모델을 실시간에서 영구히 추방하는 과정, 그리고 Deep Speech 2가 서비스에 올리기 위해 양방향을 포기하고 대신 얹은 층 하나(행 합성곱)까지 브라우저에서 직접 계산해 보는 인터랙티브 교육 자료입니다.

## 한 문단 요약

양방향 RNN은 **반대 방향으로 도는 RNN을 하나 더** 붙여 같은 시각의 두 출력을 합치는 것입니다. 셀은 그대로고 바뀌는 것은 은닉 상태를 나르는 방향뿐인데, 여기서 모든 것이 갈립니다 — 역방향 패스는 **마지막 프레임에서 시작**하므로 맨 첫 글자 `y₁` 조차 입력이 끝나기 전에는 낼 수 없습니다. 그래도 쓰는 이유는 시퀀스에서 **판별 근거가 뒤에 오는 경우가 흔하기** 때문입니다(영어 `/t/`와 `/d/`를 가르는 것은 파열이 아니라 **뒤따르는 모음의 VOT**). 이 자료의 증거 실험에서는 lookahead를 **3프레임**만 줘도 판정이 뒤집힙니다 — 발화가 끝날 때까지 기다릴 필요가 없다는 뜻이고, 이것이 DS2의 타협 근거입니다. DS2 배포 모델은 순환층을 전부 단방향으로 되돌리고 맨 위에 **미래 τ칸만 훔쳐보는 층 하나**를 얹습니다. 이것이 **행 합성곱(row convolution, = lookahead convolution)**, 식 (11)이고 **단방향 RNN을 쓸 때만 추가되는 층**입니다 — 양방향 모델에는 존재하지 않습니다. 지연이 *발화 길이 비례*에서 *τ·프레임 간격의 상수*(19 × 40 ms = **760 ms**)로 바뀌고, 중국어 CER은 5.81 → 6.10, 상대 5% 손해에 그쳤습니다. 한편 양방향이 **아예 불가능한** 과제도 있습니다 — 다음 토큰 예측에서는 역방향 상태에 정답이 이미 들어 있어 **라벨 누수**가 됩니다(BERT가 MLM을 만든 이유, Transformer가 causal mask를 쓰는 이유).

## 다루는 내용

| 절 | 주제 | 인터랙티브 데모 |
|---|---|---|
| §1 | 방향이란 무엇인가 — 두 방향은 서로를 보지 않는다 | **시간 전개 재생기** — 세 구조가 언제 출력할 수 있는지. 양방향은 **2단계**로 재생된다: ① 입력이 도착하는 동안 정방향만 전진하고 역방향은 한 칸도 계산하지 못함 → ② 입력이 끝난 뒤에야 역방향이 오른쪽에서 왼쪽으로 쓸고 내려오며 출력이 `y₁₂`부터 거꾸로 확정 — **첫 글자 `y₁`이 맨 마지막** |
| §2 | 누가 무엇을 보는가 | **의존성 행렬** — 단방향 = 하삼각, 양방향 = 꽉 참, 행 합성곱 = 하삼각 + 폭 τ의 띠. 칸을 클릭하면 그 관계가 어떤 경로로 생기는지(또는 왜 없는지) 설명 |
| §3 | 왜 더 정확한가 — 증거는 늦게 도착한다 (VOT) | **증거 도착 실험** — τ를 올리다 **τ=3에서 `/t/` → `/d/`로 판정이 뒤집힘**. "흩어져 있다" 설정에서는 τ=1이 오히려 틀린 쪽으로 가는 **비단조성**도 확인 |
| §4 | concat이냐 sum이냐, 입력 가중치는 공유하는가 | **파라미터 계산기** — 양방향은 정확히 2배가 아님. 기본 설정(GRU·161·800·5층·concat)에서 **2.87배**, DS2 식 (6)(sum·W 공유)에서는 **1.54배** |
| §5 | 양방향으로 못 하는 것 — 라벨 누수 | 과제별 가능/불가 표 (인코더는 양방향, 디코더는 단방향) |
| §6 | **DS2의 타협 — 행 합성곱(lookahead convolution)** | **지연·파라미터 예산 계산기** — τ=19·40 ms = 760 ms 상수 지연, 행 합성곱 파라미터 51,200개, 채널을 섞었다면 131 M(**×2,560**). K를 올리면 lookahead가 층마다 **누적**되는 것 |
| §7 | 실무 메모 — 패딩이 역방향을 망가뜨린다 | **패딩 오염 시뮬레이터** — `pack_padded_sequence`를 끄면 역방향이 PAD부터 읽어 6스텝 오염 |
| §8 | 그 뒤 — BERT·GPT, 청크 어텐션, RNN-T | 대응 표 |
| §9 | 정리 — 세 구조 한 장 비교 | — |
| §10 | 이해도 퀴즈 | 7문항 |

## 이 페이지가 답하는 질문

- 양방향의 첫 출력 `y₁`은 왜 **입력이 끝나야** 나오는가? (역방향 패스가 `x_T`에서 시작하니까 — 정확히는 역방향이 처음까지 되돌아온 뒤다)
- 양방향은 층을 두 개 쌓은 것인가? (아니다 — 같은 층이 **나란히** 두 방향으로 돈다. 깊이는 그대로)
- 두 방향은 서로의 상태를 보는가? (아니다 — 보게 만들면 순환이 생겨 계산 순서가 정의되지 않는다)
- 왜 음성에서 특히 차이가 큰가? (`/t/` vs `/d/`의 증거는 자음이 아니라 **다음 모음**에 있다)
- 양방향 파라미터는 정확히 2배인가? (concat이면 위층 입력 차원까지 2배라 **2배보다 더**, sum+공유면 **2배보다 덜**)
- 양방향으로 언어 모델을 만들면? (손실은 0에 가까워지고 아무것도 배우지 못한다 — **라벨 누수**)
- **행 합성곱은 양방향 모델에도 붙는가?** (아니다 — **단방향일 때만** 추가되는 층이다)
- 행 합성곱이 채널을 섞지 않는 이유는? (섞으면 파라미터가 정확히 `d`배 = 2,560배)
- 양방향 LSTM의 요약 벡터로 `out[-1]`을 써도 되나? (안 된다 — 뒤 절반은 역방향이 **막 출발한** 상태)

## 세 구조 한 장 요약

| | 단방향 | 양방향 | 단방향 + 행 합성곱 |
|---|---|---|---|
| t가 보는 범위 | `1..t` | `1..T` | `1..t+τ` |
| 첫 출력 | 즉시 | 입력이 끝난 뒤 | `τ·간격` 뒤 |
| 지연의 종류 | 없음 | **발화 길이 비례** | **상수** |
| 순환층 파라미터 | 1배 | 약 2배 (§4) | 1배 + `(τ+1)·d` |
| 언어 모델 | 가능 | 불가 (라벨 누수) | 불가 |
| 대표 사례 | 스트리밍 ASR, char-rnn | DS2 연구용 모델, 태깅, BERT | DS2 배포 모델 |

## 숫자에 대하여

DS2 관련 수치(τ = 19 · 프레임 간격 40 ms · 중국어 CER 5.81 → 6.10 · 은닉 2560 단방향 5층)는 [Amodei et al. (2015)](https://arxiv.org/abs/1512.02595)의 값이고, 나머지 — 파라미터 계산기의 모든 수, 지연 막대, 증거 실험의 확률, 패딩 오염 스텝 수 — 는 브라우저에서 그 자리에서 계산한 결과입니다.

§3의 증거 실험은 "보이는 프레임의 로그 오즈를 더한다"는 **장난감 모델**입니다. 실제 RNN은 증거를 더하지 않고 비선형으로 섞으며 게이트로 지우기도 합니다. 다만 **창 밖의 증거는 출력에 전혀 영향을 줄 수 없다**는 성질만은 구조가 보장하는 것이라 그대로이고, 이 데모가 보여 주려는 것도 그 성질 하나입니다. 페이지 안에도 같은 주의를 적어 두었습니다.
